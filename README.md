# Zengge для Windows

Управление LEDnetWF через Bluetooth LE: несколько ламп, RGB-палитра, яркость и цветомузыка от системного звука или выбранного приложения.

**[Скачать последнюю версию для Windows x64](https://github.com/Pavel-Karpov-2002/Remote-control-Zengge-from-PC/releases/latest/download/ZenggeMusic.exe)**

Установка Python не нужна. Запустите `ZenggeMusic.exe` из [Releases](https://github.com/Pavel-Karpov-2002/Remote-control-Zengge-from-PC/releases).

## Подключение ламп

1. Включите Bluetooth на ПК и питание лампы. Закройте приложение лампы на телефоне, если оно удерживает соединение.
2. Нажмите «Найти», выберите лампу и нажмите «Подключить».
3. Выберите следующую лампу и снова нажмите «Подключить». При необходимости повторите поиск.
4. Все подключённые лампы получают общий цвет, яркость, питание и музыкальный режим.
5. Чтобы отключить отдельную лампу, выделите её в таблице и нажмите «Отключить выбранные». Несколько строк выделяются с Ctrl/Shift. При закрытии окна отключаются все лампы.

Обрыв связи с одной лампой не останавливает остальные. Число одновременных подключений и возможность поиска при активных соединениях зависят от Bluetooth-адаптера и драйвера. Новое подключение не отменяет существующие. Цвет в окне показывает выбранное/отправляемое значение, а не подтверждённое состояние лампы.

## Цвет и яркость

Нажмите «Включить». Во вкладке «Цвет» выберите оттенок через «Палитра…» или поля R/G/B (0–255), затем «Применить цвет». Общая «Яркость» (0–100%) регулирует ручной свет и ограничивает максимальный уровень музыки.

## Музыка

Подключите лампы, откройте вкладку «Музыка», выберите источник и нажмите «Запустить». Лампы включатся автоматически.

| Настройка | Действие |
| --- | --- |
| Источник | Весь системный звук с выхода Windows по умолчанию либо отдельное приложение вместе с дочерними процессами |
| Обновить | Обновляет список окон и звуковых сеансов на всех активных выходах; запускать звук заранее не нужно |
| Чувствительность | Усиление анализа тихого/громкого звука и масштаб осциллограммы |
| Яркость в такт музыке | Включает изменение яркости по уровню звука; без флажка яркость постоянная |
| Сила пульсации | Глубина изменения яркости при воспроизведении: 0% — постоянная, 100% — максимальная реакция |
| Плавность | Сглаживание переходов цвета и яркости; вправо — более медленные и мягкие переходы |
| Звуковая волна | Осциллограмма реального сигнала выбранного источника |

**При паузе, тишине и завершении песни сохраняются последний цвет и яркость.** Это действует и с включённой реакцией яркости. При возобновлении звука изменения продолжаются. «Остановить» завершает музыкальный режим и возвращает ручной цвет. «Выключить» останавливает режим и выключает все подключённые лампы.

Для смены источника остановите режим. Если приложение перезапустилось, обновите список и выберите его снова. Заголовок окна помогает найти нужное приложение, но захват идёт по процессу и его дочерним процессам: вкладки одного браузера отдельно не разделяются. Окно без аудиопотока можно выбрать заранее — сигнал появится, когда оно начнёт воспроизведение. Фоновые приложения без окна и без звукового сеанса до появления сеанса могут отсутствовать.

Общий звук использует WASAPI loopback; микрофон не нужен. Аудио обрабатывается локально, не сохраняется и не отправляется в сеть. Для отдельных приложений нужна Windows build 20348+ / Windows 11. На более старых версиях доступен общий звук. Если отдельный захват недоступен, программа сообщает об ошибке и не переключается на общий звук. DRM-защищённое аудио может быть недоступно. Речь и системные звуки тоже влияют на музыку, если они входят в выбранный источник.

## Сборка и тесты

Python 3.12 x64 с Tkinter, Windows:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe app.py
.\build.ps1
```

Результат сборки: `dist/ZenggeMusic.exe`. Исполняемые файлы публикуются в Releases, а не в истории Git.

`check_loopback.py` — дополнительная интеграционная проверка изоляции двух процессов; она воспроизводит короткий тихий тестовый тон. Обычные unit-тесты ничего не воспроизводят и не требуют лампы.

Проверено: анализ аудио, тишина с удержанием цвета, плавные переходы, сила пульсации, список молчащих окон, изоляция аудио процессов, независимые счётчики и очереди ламп, продолжение работы при отказе одной лампы. Проверка нескольких соединений выполнена на модели BLE-транспорта; совместимость нескольких физических контроллеров требует проверки на оборудовании.

## Протокол и совместимость

Протокол основан на [8none1/zengge_lednetwf](https://github.com/8none1/zengge_lednetwf), коммит `f4d20fc3225e4b8b5637b5951fff59d91882a53c`. UUID сервиса FFFF, запись FF01, уведомления FF02. RGB преобразуется в документированный HSV-пакет 3B A1 с точностью контроллера. Транспорт — Bleak/WinRT; Linux и Home Assistant не нужны.

Автор исходного проекта перенёс дальнейшие исследования в [lednetwf_ble](https://github.com/8none1/lednetwf_ble). У моделей и прошивок команды могут отличаться. Адресное управление группами LED и встроенные эффекты в этой версии не реализованы.
