# Product

## Platform
Windows desktop x64, Python 3.12, Tkinter, Bleak/WinRT.

## Purpose
Русское настольное приложение управления LEDnetWF через Bluetooth LE: несколько ламп одновременно, RGB, общий уровень яркости, музыкальный режим.

## Capabilities and constraints
Команды всем подключённым лампам; отключение выбранных. Разрыв связи с одной лампой не отменяет остальные соединения. Реальная ёмкость адаптера зависит от оборудования.
Аудио: общий системный звук или процесс с дочерними процессами. Список из видимых окон и сеансов всех активных устройств вывода, доступен до воспроизведения.
Общая яркость, чувствительность, сила пульсации, реакция яркости, плавность переходов и реальная осциллограмма.
По подтверждённому выбору пользователя тишина/пауза удерживает последний цвет и яркость. Остановка режима кнопкой возвращает ручной цвет; выключение выключает лампы.
Данные аудио не записываются и не передаются в сеть. Группы отдельных LED отложены.
